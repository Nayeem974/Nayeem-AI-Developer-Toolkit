# OpenAI Codex

Use the portable Agent Skills folders in `.agents/skills/` and copy `AGENTS.md` plus `SKILL-ROUTER.md` to the repository root. Codex supports project guidance through `AGENTS.md`; verify skill discovery against your installed Codex version.

Run: `python scripts/install_skills.py --target codex --scope project --project /path/to/repo`. Superpowers has its own Codex plugin metadata in its source folder; follow its upstream installation guide if you want plugin-specific features.
